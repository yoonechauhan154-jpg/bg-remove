Free Background Removal API

An API for background removal that never requires uploading your images to our servers. We ship the model as a self-hosted package you run inside your own infrastructure — you get remove.bg-style output with data-center-grade privacy.

Why We're Building This

Every existing background-removal API (remove.bg, Clipdrop, PhotoRoom) sends your images to their servers and charges per image. For e-commerce catalog teams and apps handling customer photos, that means two problems: cost that scales with volume and sensitive images leaving your control.

BgClear's API packages the same in-browser model into a self-hosted container. You run it in your own cloud or on-premise, your images never cross a network boundary you don't control, and there are no per-image fees.

How It Works

  1. Deploy the container in your environment (Docker, Kubernetes, or serverless).
  2. Send image bytes to the local endpoint — POST /v1/remove-background.
  3. Receive a transparent (or white-filled) PNG with alpha mask metadata.

Code Examples — How to Call the Background Removal API

cURL Example

curl -X POST https://api.yourdomain.com/v1/remove-background \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "image=@/path/to/photo.jpg" \
  --output transparent.png

JavaScript (fetch) Example

const formData = new FormData();
formData.append('image', file); // from <input type="file">

const res = await fetch('https://api.yourdomain.com/v1/remove-background', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' },
  body: formData
});
const blob = await res.blob();
// Use the blob as <img src> or download

Replace the endpoint with your self-hosted URL. API key is sent via waitlist invite.
